# Java Text RPG Game 2

## 프로젝트 소개

Java를 사용하여 제작한 콘솔 기반 텍스트 RPG 게임입니다.

사용자는 영웅의 이름을 입력하고 직업을 선택한 뒤, 사냥터에서 몬스터와 전투하거나 포션 상점과 무기 상점을 이용하여 캐릭터를 강화할 수 있습니다.

기존 단일 파일 방식의 RPG 게임에서 발전하여, 이번 프로젝트에서는 캐릭터, 몬스터, 상점, 미션 기능을 각각 클래스로 분리하여 객체지향적인 구조로 구현하였습니다.

---

## 개발 환경

- Language: Java
- 실행 방식: 콘솔 입력 기반
- 주요 개념
  - 클래스
  - 상속
  - 메서드 오버라이딩
  - 객체 생성
  - 조건문
  - 반복문
  - Scanner 입력 처리

캐릭터 상속 구조

이 프로젝트는 캐릭터 구조를 상속으로 구현하였습니다.

Character

│   └── Archer

    ├── Racoon
    ├── WildCat
    ├── WildDog

Character 클래스는 이름, 레벨, HP, MP를 공통 속성으로 가지고 있습니다.

Hero 클래스는 Character를 상속하며 공격력, 방어력, 골드, 경험치 속성을 추가로 가집니다.

Monster 클래스도 Character를 상속하며 몬스터의 공격력, 방어력, 골드 보상, 경험치 보상을 관리합니다.

전투 시스템

전투는 영웅이 먼저 공격하고, 몬스터가 살아있으면 몬스터가 반격하는 방식으로 진행됩니다.

영웅의 공격은 직업별 attack() 메서드에서 처리됩니다.

전사는 전사용 스킬을 선택하고, 마법사는 마법 스킬을 선택하며, 궁수는 화살 스킬을 선택합니다.

몬스터가 처치되면 영웅은 몬스터의 경험치와 골드를 획득합니다.

hero.exp += monster.exp;
hero.gold += monster.gold;
특수 데미지 시스템

일부 직업 스킬은 특정 몬스터에게 더 강한 데미지를 줍니다.

직업	스킬	대상 몬스터	효과
전사	싸커킥	살쾡이	데미지 2배
마법사	아이스 볼	들개	데미지 2배
궁수	얼음 화살	멧돼지	데미지 2배

이를 통해 단순 공격뿐만 아니라 직업과 몬스터의 상성을 고려한 전투 구조를 구현하였습니다.

레벨업 시스템

영웅의 경험치가 현재 레벨 기준 필요 경험치 이상이 되면 레벨업합니다.

레벨업 조건은 다음과 같습니다.

hero.exp >= hero.level * 80

레벨업 시 다음 효과가 적용됩니다.

레벨 1 증가
경험치 0으로 초기화
레벨업 보상 골드 지급
레벨에 따른 미션 생성

골드 보상 공식은 다음과 같습니다.

hero.gold += hero.level * 50;
미션 시스템

레벨업 시 레벨에 맞는 미션이 생성됩니다.

레벨	미션	보상
2	너구리 3마리 처치	50원
3	살쾡이 2마리 처치	80원
4 이상	멧돼지 5마리 처치	100원

몬스터를 처치할 때마다 미션 진행도가 증가하고, 목표 수치를 달성하면 미션 보상을 받을 수 있습니다.

포션 상점

게임 메뉴에서 2. 포션 상점을 선택하면 포션을 구매할 수 있습니다.

번호	아이템	가격	효과
1	힘 증강 포션	30원	공격력 +3
2	방어력 증강 포션	30원	방어력 +3
3	경험치 증강 포션	100원	경험치 +50
4	HP 증강 포션	10원	HP +50
5	MP 증강 포션	10원	MP +50

골드가 부족하면 구매할 수 없으며, 구매 불가 메시지가 출력됩니다.

무기 상점

게임 메뉴에서 3. 무기 상점을 선택하면 직업별 무기를 구매할 수 있습니다.

직업	무기 이름	가격	효과
전사	대검	100원	공격력 +100
마법사	간달프 지팡이	100원	공격력 +100
궁수	버드나무로 만든 활	100원	공격력 +100

무기에는 직업 제한이 있습니다.

예를 들어 전사는 대검만 구매할 수 있고, 마법사는 지팡이만 구매할 수 있으며, 궁수는 활만 구매할 수 있습니다.
